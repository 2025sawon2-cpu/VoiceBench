    REST

    서버의 API 키를 Bearer 토큰으로 전달하세요. 화면에는 키를 표시하지 않습니다.

    POST /v1/tts
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{"text": "안녕하세요. 오늘의 이야기입니다."}

    GET /v1/tts/{id}로 진행 상태를 확인한 뒤, 응답의 audio_url에서 WAV를 받습니다.
