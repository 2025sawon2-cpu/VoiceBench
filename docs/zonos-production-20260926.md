# ZONOS2 기본 모델 전환 — 2026-09-26

사용자는 ZONOS2를 기본으로 채택하되 **기존 본인 목소리 복제**를 유지하도록 지정했다. 모델 가중치를 추가 학습하거나 정밀도를 낮추지 않았다.

## 적용 설정

| 항목 | 값 |
|---|---|
| Studio / 외부 API 기본 | `zonos2-q8-experimental` (기존 식별자 유지) |
| 모델 / 추론 | 공식 ZONOS2 Q8_0 / CUDA |
| 음성 | 본인 B 레퍼런스 9.95초, 기존 파일/해시 유지 |
| 기본 Seed / 모드 | 13 / long_form_hq |
| 샘플링 | temperature 0.9, top_p 0.95, min_p 0.05 |
| 감정 / 속도 지시 | 꺼짐 |
| 파형 복원 DAC | CPU, 동시 디코딩 1개 |
| 비교 모델 | Qwen 유지, 공식 AmericanMale 별도 선택 |

## 변경

- ZONOS2는 공백 정리 후 240자 이하 대본을 한 번에 생성한다. 긴 대본은 기존 약 180자 목표/240자 상한의 의미·문장·문단 분할을 유지한다. 모델 선택을 바꾸면 UI 미리보기도 다시 계산한다.
- Studio/HQ ZONOS2에 CPU Whisper 누락·반복 검사를 연결했다. Seed 13 실패 시 10, 42로 재시도하고, 검사 통과 후보를 우선한다. 모두 실패하거나 음성 인식 검증을 사용할 수 없으면 실패로 처리한다. 실패 후보 및 검사 기록은 로컬 출력 폴더의 `job-*-quality-failed.json`에 보존한다.
- 벤치마크는 요청한 Seed를 그대로 유지한다. 자동 검사는 자연스러움·화자 유사성을 보장하지 않는다.
- 외부 API는 엔진·레퍼런스·Seed를 서버가 결정한다. 새 정책의 요청 캐시 버전을 올려 이전 Qwen/분할 결과를 동등한 요청으로 재사용하지 않는다.
- 공식 남성 프리셋은 개인 레퍼런스와 다른 프로젝트를 사용한다. 프로젝트 레퍼런스를 쓰는 벤치마크에서는 해당 프리셋 선택을 거부하여 이름과 실제 화자가 달라지는 일을 막는다.
- Qwen 전용 실험 도구는 서비스 기본 엔진과 분리했다. 기본 모델이 바뀌어도 Qwen 설정/워커를 사용한다.
- 화자 임베딩 캐시는 내용 해시 기반 최대 4개이며, 레퍼런스 내용이 바뀌면 재계산한다.
- 워커 런타임 버전 확인을 추가했다. 모델 이름만 같은 구버전 워커를 재사용하지 않는다. 소유한 워커의 정상 종료와 자식 정리를 기다린 후 새 모델을 시작한다.
- 웹 결과에 처리 시간(로딩·검사 포함)과 GPU 메모리 사용률이 높았는지 표시한다.
- `tools/match_comparison_volume.py`는 원본을 덮어쓰지 않고 일정한 gain으로 RMS를 맞춘 비교 사본을 만든다. 피크 제한을 함께 적용한다. LUFS 정규화나 지각적 동등 음량의 보장은 아니다.

## 성능 진단

다른 프로젝트의 모델 서버가 같은 GPU에서 약 5.1GiB의 전용 메모리를 사용 중이었다. 해당 프로세스는 변경하거나 종료하지 않았다.

ZONOS2 프로세스의 Windows GPU 메모리 카운터에서 공유 메모리는 약 1,036MiB에서 460MiB로 감소했다. 전용+공유의 합은 약 627MiB 감소했다. 측정은 서로 다른 시점의 관측값이며, 공유 메모리 자체가 모든 속도 저하의 원인이라는 증명은 아니다.

공식 AmericanMale, 아디다스 전체 대본, Seed 13의 직접 합성은 GPU DAC 약 151.2초, CPU DAC 약 151.5초였다. **속도 향상은 확인되지 않았다.** 같은 대본의 출력 길이는 모두 15.801초였다. 두 PCM은 같은 프레임 수이며, 차이의 RMS는 16비트 PCM 단위 6.07, 신호 대비 오차비는 약 51.7dB였다. 청취 평가를 대신하지 않는다.

이전 GPU 단독에 가까웠던 비교에서의 8~13초 합성 속도가 복구됐다고 주장할 수 없다. 현재 CPU DAC는 메모리 절감을 위해 채택한다. 예측 가능한 처리 시간이 필요하면 운영자가 다른 GPU 모델과의 동시 상주를 줄이는 환경에서 다시 측정해야 한다. Q8을 자동으로 낮은 정밀도로 바꾸거나 다른 서비스를 강제 종료하지 않는다.
