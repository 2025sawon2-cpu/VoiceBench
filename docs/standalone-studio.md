# VoiceBench 독립형 Studio

## 실행

VoiceBench 폴더의 `Start-Studio.cmd`를 더블클릭합니다. 기존 서버가 있으면 재사용하고, 없으면 이 프로젝트의 Python 가상환경으로 로컬 서버를 시작합니다. 브라우저 주소는 http://127.0.0.1:8765 입니다. 자동화 프로그램을 실행하지 않아도 사용할 수 있습니다. 모델 설치와 가상환경은 기존 VoiceBench 설치를 사용합니다.

실행기는 기존 `.runtime/external-api-key.txt`를 서버 환경으로 전달하며 키를 화면에 출력하지 않습니다. 시작 오류는 `.runtime/studio-launch.log`에서 확인합니다. 이번 UI는 현재 PC용이며 외부 공개나 다중 사용자 계정 서비스는 포함하지 않습니다.

## 화면 기능

- **음성 만들기**: 대본 작성, TXT 불러오기/저장, 브라우저 자동 저장, 모델/목소리/Seed/HQ 선택, 실제 생성 구간 미리보기. 생성 후에도 대본을 유지합니다.
- **목소리 보관함**: WAV·MP3·M4A 등 브라우저가 읽을 수 있는 녹음(최대 30MB/5분)에서 3~30초를 골라 자동 변환하고 등록합니다. 구간 미리듣기와 로컬 한국어 자동 대본 인식, 직접 수정을 지원합니다. 등록한 원본을 재생하고 생성 화면에서 선택합니다. 본인 또는 허락받은 녹음을 사용하세요.
- **생성 기록**: 최근 50개 요청 검색과 상태 필터, 전체 대본 펼치기, 진행 상태/QA/재시도 Seed, WAV 재생과 다운로드, 장별 다운로드, 취소, 대본과 설정 다시 사용.
- **비교 실험**: 프로젝트별 대본·레퍼런스·모델·여러 Seed의 조합으로 평가합니다. 블라인드 비교와 집계를 유지합니다.
- **모델 관리**: 등록된 모델 확인과 기존 Command 어댑터 등록. 모델 설치나 학습을 자동으로 수행하는 화면은 아닙니다.
- **자동화 연결**: 외부 REST 요청 형식, 고정 정책, 기존 MCP 연결 진입점을 안내합니다. API 키를 노출하지 않습니다.

ZONOS2 기본값은 기존 본인 목소리, Seed 13, 장문 HQ입니다. AmericanMale 모델은 공식 목소리로 고정되어 보관함 목소리 선택이 비활성화됩니다. 다른 모델에서는 사용자 목소리를 선택할 수 있습니다. 모델별로 지원하는 언어·품질·사용 조건은 다릅니다.

## 데이터와 API

별도 프런트엔드 프레임워크나 패키지 설치 없이 기존 정적 HTML/CSS/JS와 Python 서버를 사용합니다. UI 확장 파일은 `voicebench/static/workspace.css`, `workspace.js`입니다.

보관함 목소리는 projects의 `description=voice-library:v1`로 구분합니다. 업로드 후 원본과 대본은 변경할 수 없으며 수정할 때는 새 목소리로 등록합니다. 이 방식은 대기 중인 작업이 다른 레퍼런스로 생성되는 것을 막습니다. 음성 파일은 콘텐츠 해시로 보관합니다. 기본 음성 선택과 요청별 고급 설정은 studio_requests의 voice_id / generation_json에 저장되며, 서버 시작 시 호환 마이그레이션을 적용합니다.

- `POST /api/voices`: WAV 본문, URL 인코딩한 `X-Voice-Name`, `X-Reference-Text` 헤더. 최대 12MB.
- `GET /api/voices/{id}/audio`: 웹 인증 정책을 적용한 원본 재생.
- `POST /api/studio/synthesize`: 웹 전용 선택 필드 `voice_id` 또는 `voice_project_id`, 요청별 `generation`. 기본값은 기존 모델의 레퍼런스. 두 목소리 필드는 동시에 지정할 수 없습니다.
- `/api/studio` 응답에 `voices`, 모델별 `fixed_voice`, 요청별 `voice_name` 추가.
- 외부 `/v1/tts`는 계속 서버가 모델·목소리·Seed·HQ를 결정합니다. 웹의 선택은 외부 요청에 전파되지 않습니다.

대본 자동 저장은 해당 브라우저의 localStorage이며 계정 동기화가 아닙니다. 사용 환경에서 저장소가 차단되면 TXT 저장을 이용합니다. 파일/목소리/고급 설정은 모델 설치 상태에 따라 실제 생성 가능 여부가 달라집니다.

## 참고 프로젝트

[VoiceStudio](https://github.com/debpalash/VoiceStudio)의 작업별 메뉴와 생성 흐름, [XTTS-WebUI](https://github.com/daswer123/xtts-webui)의 레퍼런스와 모델 설정 구성을 검토했습니다. VoiceStudio의 현재 라이선스는 AGPL-3.0-only, XTTS-WebUI는 MIT로 표기되어 있습니다. 이번 구현에 두 프로젝트의 소스·이미지·스타일·의존성을 복사하거나 포함하지 않았습니다. VoiceBench의 기존 코드에 자체 UI를 구현했습니다.

## 검증 (2026-09-26)

Python 전체 회귀 75개와 Node UI 로직 8개 통과. 새 보관함의 업로드 검증·수정 차단·작업 연결·외부 API 분리, 웹의 목소리/HQ 전달·중복 제출 방지·대본 유지 검사 포함.

실제 브라우저에서 대본 입력, 본인 녹음 등록, 목소리 선택, 기록 검색과 재사용, 모델 전환 및 실제 ZONOS2 요청 #32를 확인했습니다. 결과는 3.959초이며 Seed 13, HQ 첫 검사 통과, 재생성 0회였습니다. UI 변경이 음색의 개선을 의미하지는 않습니다. 기존 모델과 생성 설정을 그대로 사용합니다.

재생 검증 제한: Codex 내장 브라우저에서 반응형 화면 검사 후 오디오 재생을 시도할 때 탭 오류가 한 번 발생했습니다. 새 탭에서 화면은 복구됐습니다. 생성 WAV의 다운로드와 파싱은 정상이며, 내장 브라우저의 실제 재생 완료는 검증하지 못했습니다. 실행 파일은 기본 웹 브라우저를 엽니다. 오류 원인이 앱인지 브라우저인지 확정하지 않았습니다.


## 목소리 갤러리 (2026-09-27)

생성 화면의 ‘목소리 변경 · 미리듣기’에서 선택 창을 엽니다. 카드를 선택하면 저장된 샘플을 즉시 재생하고, 재생 버튼만 누르면 선택은 유지한 채 다른 목소리를 들어볼 수 있습니다. 플레이어는 화면 아래에서 계속 재생됩니다. 이름/분위기/언어 검색, 성별·모델 필터, 브라우저 즐겨찾기를 제공합니다.

- ZONOS2: 공식 참조 음성 AmericanMale, AmericanFemale, BritishFemale 3개.
- Qwen: CustomVoice의 공식 화자 9명. 기존 Base 음성 복제 모델과 별도로 설치됩니다. 소희는 한국어 기반이며 다른 화자는 영어·중국어·일본어 기반입니다.
- Qwen Base / VoxCPM2 / Fish / Chatterbox: 각각 공용 합성 남녀 목소리 2개. Qwen 소희·에이든으로 만든 합성 참조를 해당 모델로 복제합니다. 해당 엔진의 공식 내장 화자로 표시하지 않습니다.
- 본인 목소리와 등록 녹음: 원본 녹음 즉시 재생. 모델 출력과 구분해 표시합니다.

`한국어 샘플`은 해당 모델이 생성한 캐시 WAV입니다. `원본 미리듣기`는 참조 녹음이며 현재 모델의 출력이 아닙니다. 재생 GET은 작업 큐/GPU를 사용하지 않습니다. 모델 설정이나 참조가 바뀌면 이전 캐시를 모델 출력으로 잘못 표시하지 않습니다. 고급 설정을 변경해도 저장 샘플은 바뀌지 않으며, 변경한 결과는 대본 생성으로 확인합니다.

Temperature, Top P/K, 반복 억제, 추론 단계, Seed와 검사 모드는 ‘고급 설정 · 직접 조정’ 안에 있습니다. 지원되는 항목만 표시하고 서버도 범위를 검증합니다. Qwen CustomVoice에는 선택적 낭독 지시가 있습니다. 기본값에는 감정 지시를 넣지 않습니다. 웹 요청의 변경은 서버의 기본 설정을 덮어쓰지 않습니다.

새 API:
- `/api/studio`: `voice_catalog`와 모델별 `custom_controls`.
- `GET /api/voice-catalog/{id}/preview`: 인증 적용, 오디오 Range 지원, 추론 없음.
- 생성 기록은 `voice_id`와 `generation`을 함께 복원합니다.

샘플은 `data/voice-gallery/previews`에 저장됩니다. VoiceBench 서버를 종료하고 대기/실행 작업이 없을 때 `tools/prepare_voice_gallery.py`로 재생성합니다. 이미 검증한 캐시는 건너뜁니다. 발음/파형 검사를 통과한 결과만 공개하며 실패 시 시드 1회 재시도 후 실패를 기록합니다. 이 검사는 사람의 음색 선호나 자연스러움을 보증하지 않습니다.

상세 소스 비교: [VoiceStudio 검토 및 적용 기록](voicestudio-benchmark-20260927.md).


최종 검증: 한국어 생성 샘플 20개 모두 준비, HTTP 조회/WAV 파싱 성공. Python 81개 + UI 12개 검사 통과. 브라우저에서 소희 5.44초 샘플 재생 완료를 확인했으므로 위 2026-09-26의 ‘실제 재생 완료 미검증’ 제한은 이번 갤러리 플레이어에서는 해소됐습니다. 실제 생성 #33(소희, Temperature 0.95) 성공 및 목소리/설정 재사용 확인.


## 사용성 개선 (2026-09-28)

- 메인 화면은 대본과 현재 목소리, 하단 고정 생성 버튼을 중심으로 구성합니다. 갤러리는 별도 대화상자로 분리했고 카드를 선택하면 작성 화면으로 돌아와 대본에 초점을 둡니다. 검색/샘플 듣기만으로 생성 목소리는 바뀌지 않습니다.
- 기본 목소리 / 내 목소리 / 모델별 비교를 구분합니다. 같은 화자를 여러 모델로 복제한 카드가 있으므로 개수는 ‘선택 항목’으로 표시합니다. 고급 수치는 기존 고급 설정에서 조정합니다.
- 서버 연결 상태와 연결 끊김 안내, 재연결 버튼이 있습니다. 연결 실패 시 생성 제출을 차단하고 자동으로 다시 확인합니다. 정적 UI 파일 버전이 바뀌면 새로고침을 안내하며, 대본은 localStorage, 선택/Seed/검사/고급 설정은 해당 탭의 sessionStorage에 보존합니다. 등록 중인 원본 파일과 편집 상태는 새로고침 시 다시 선택해야 합니다.
- 녹음 변환/자르기는 브라우저에서 처리하고 선택한 구간만 24kHz 모노 PCM16 WAV로 서버에 보냅니다. 코덱 지원은 브라우저에 따라 달라지며, 해독 실패 시 WAV/MP3 대체 안내를 표시합니다. 원본 파일은 변형하지 않습니다.
- `POST /api/voices/transcribe`: 기존 웹 인증 적용, PCM16 WAV 3~30초/최대12MB. 기존 로컬 Whisper Base로 한국어를 인식하며 CPU만 사용합니다. 동시 실행 1개, 프로세스 제한110초, 임시 구간은 완료/실패 시 정리합니다. 별도 모델 다운로드나 TTS 작업 생성은 없습니다. 인식은 보조 기능이므로 결과를 듣고 수정해야 합니다. 파일/구간 변경이나 인식 중 직접 입력을 늦게 도착한 응답이 덮어쓰지 않습니다.
- 검증: Python 85개 / Node UI 19개 통과. 실제 브라우저에서 샘플 재생, Qwen 필터와 ZONOS2 실제 선택 분리, 카드 선택 후 복귀, 새 버전 갱신 후 대본·선택 유지, WAV와 MP3 변환, 5.4초→4초 구간 편집, 한국어 문장 자동 인식을 확인했습니다. 390px 뷰포트에서 가로 넘침 없이 생성 버튼 표시. 실제 서버 중단 후 연결 끊김/생성 차단/대본 보존, 재시작 후 자동 재연결을 확인했습니다.

## PC별 독립 실행 설정

같은 코드를 여러 PC에서 사용해도 설치 엔진과 자료는 각 PC에 보관합니다.
서버 시작 시 `.runtime/studio-settings.json`의 `default_engine_slug`를 읽습니다.
파일이 없으면 기존 ZONOS2 기본값을 유지합니다. 예를 들어 기존 Qwen 설치를
사용하는 PC에서는 다음과 같이 설정할 수 있습니다.

```json
{"default_engine_slug": "qwen3-tts-17b-pascal-expressive"}
```

설정 변경 후 큐가 비었을 때 서버를 다시 시작합니다. 웹 기본 선택·분할 미리보기·
외부 API가 같은 서버 설정을 사용하며, 외부 호출자가 엔진·목소리·Seed를 바꾸는
기능은 추가하지 않았습니다. 기본 개인 레퍼런스, 외부 Seed 13, HQ 정책은 유지됩니다.
파일은 Git에서 제외됩니다. 설치되지 않은 엔진으로 설정하면 다른 엔진으로 자동
대체하지 않습니다. `/v1/health`의 `ready`, `errors`는 등록된 기본 엔진과 실행 경로,
참조 파일의 준비 상태를 나타내며 실제 음성 생성 품질을 보증하지 않습니다.

외부 `/v1/tts` 요청은 선택적으로 `generation_key`(영문·숫자·밑줄·하이픈,
최대 100자)를 받을 수 있습니다. 명시적 음성 재생성에는 새 키를 사용하고,
동일 요청의 재시도에는 같은 키를 유지합니다. 키가 다르면 기존 완료 음성
캐시를 재사용하지 않습니다. 엔진·참조 목소리·Seed 13·HQ는 여전히 서버가
결정하며, 키를 생략한 기존 호출의 캐시 동작은 유지됩니다.
