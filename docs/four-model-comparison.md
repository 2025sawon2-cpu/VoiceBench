# 네 모델 한국어 음성 복제 비교

2026-09-24. 목표는 RTX 4070 Ti SUPER 16GB에서 실용적인 음질을 우선하는 로컬 비교다.
청감 우열과 화자 유사도는 청취로 판단해야 하며, ASR CER만으로 자연스러움을 순위화하지 않는다.

## 공통 조건

- 사용자가 제공한 아디다스 가방 대본 143자를 수정 없이 사용한다.
- 선택된 동일 참조 음성 약 9.95초, Seed 13. 전사문을 사용하는 모델에는 동일 전사문을 제공하며, ZONOS2는 음성 임베딩만 사용한다.
- 감정/스타일 지시, 피치/속도 후처리, 생성 후 음량 가공 없음.
- 서로 다른 모델의 Seed 숫자가 같다고 동일 난수 과정이 되는 것은 아니다.
- 한 GPU에서 직렬 실행한다. 로드/교체 시간과 실제 합성 시간을 구분한다.
- 참조 음성과 생성 결과는 로컬에만 보관하고 Git에서 제외한다.

## 구현

| 엔진 | 설정 | 근거/한계 |
|---|---|---|
| Qwen3-TTS 1.7B Base | FP16, SDPA, T1.0/P0.95 | 기존 운영 프리셋. 자연어 감정 지시 없음 |
| VoxCPM2 | BF16, SDPA, CFG 2.0, 20단계 | 10단계 원본도 보존. 더 많은 단계가 자동으로 더 좋은 음질을 뜻하지 않음 |
| Fish S2-Pro | 원본 BF16, 공식 SDPA math 디코딩, T0.8/P0.8/K30 | 캐시 4096, 생성 상한 2048. 가중치 양자화 없음 |
| ZONOS2 | 공식 Q8_0 GGUF, 로컬 CUDA 빌드, batch 1 | accurate_mode=true, emotion_enabled=false, T0.9/P0.95/minP0.05 |

Fish는 네트워크 두 개를 동시에 GPU에 상주시켰을 때 첫 시험에서 약 15.5GiB를
할당했다. 메모리 여유를 확보하기 위해 참조 인코딩 → 의미 토큰 생성 → 파형 디코딩
단계마다 모델과 코덱을 CPU/GPU 사이에서 교대 배치한다. 파형을 잘라 디코딩하거나
가중치를 더 낮은 정밀도로 양자화하지 않는다. 4096 캐시는 이번 단문용이며 임의의 긴
참조/대본에 무제한 대응하지 않는다. 초과 입력은 공식 구현이 오류로 거부한다.

ZONOS2는 15.3GB F16 백본에 캐시·디코더·데스크톱 GPU 사용량까지 더하면 16GB에서
여유가 없으므로 약 8.5GB Q8_0를 사용한다. F16과 동일한 출력이라고 주장하지 않는다.
공식 C++ 소스의 CUDA 빌드를 Python 작업자로 감싸 기존 모델 교체·큐·결과 기록을 재사용한다.
내부 서버도 127.0.0.1에만 바인딩하며 외부 오디오 서비스에 요청하지 않는다.

배포 바이너리는 이 PC에서 CPU 화자 인코더를 로드할 때 `0xC000001D`
(illegal instruction)로 종료됐다. CPU 명령어 호환성 문제로 추정되며 정확한
명령어 위치까지 디버깅한 것은 아니다. ZONOS2 공식 Python 구현이 사용하는
동일 ECAPA 화자 인코더와 전처리를 FP32 CPU에서 실행하여 NPY 임베딩을 서버에
전달한다. 모델 디렉터리에는 백본/디코더 하드 링크만 만들어 C++ CPU 인코더의
자동 로드를 방지한다. 원본 모델 파일은 유지한다. 화자 모델은 다른 임의의
인코더로 대체한 것이 아니다.

## 재현과 의존성

`install-fish-zonos.ps1`은 별도 가상환경과 고정 소스/모델 버전을 사용한다.
`build-zonos2-cuda.ps1`은 로컬 MSVC 14.44/Windows SDK 22621/CUDA 12.9.1로
SM89 GPU 및 AVX2 CPU 빌드를 만든다. 도구는 `.runtime/toolchains` 아래에 두며
NVCC의 한글 경로 문제를 피하려고 빌드 중에만 비어 있는 V: 드라이브를 매핑한다.
다른 GPU는 `-Architecture`를 지정한다. V:가 사용 중이면 `-BuildDrive`로 다른 문자를 선택한다.
`tools/download_fish_zonos.py`는 다운로드 재개 및 ZONOS2 배포 SHA256 검증을 수행한다.

- Fish 소스: `214da3cd841bda85da2496b96cd3c4d7edb1337e`
- Fish 모델: `1de9996b6be38b745688de084d87a5633f714e4e`
- ZONOS2 바이너리: `v0.5.1`
- CUDA 소스: `39a4d01558db86dca1219273992c77ebc8e03991`, GGML `3af5f5760e19a96427f5f7a93b79cbdf3d4b265b`
- ZONOS2 GGUF: `75c877ec8ac86dda42bfc0e9968c87f29e10ef57`
- 공식 ZONOS2에서 참조하는 ECAPA 모델: `marksverdhei/Qwen3-Voice-Embedding-12Hz-1.7B`,
  revision `7577f61c42737fc8064bba773e2a18602df92803` (로컬 코드 검토, 오프라인 로딩).
- Fish Torch/Torchaudio 2.8.0+cu126, Transformers 4.57.3.

Fish 공식 uv 구성과 동일하게 protobuf>=3.20,<6을 강제한다. 상위 패키지
descript-audiotools의 오래된 protobuf<3.20 선언과 충돌하므로 `pip check`에는 이 알려진
충돌이 남는다. 의존성이 완전히 무충돌이라고 주장하지 않는다. 설치 환경의 실제 음성
합성과 회귀 검증 결과를 별도로 기록한다.

Built with Fish Audio. Fish의 코드와 가중치는 Fish Audio Research License이며,
상업적 사용은 별도 계약 대상이다. 본 엔진 이름에도 연구/비상업 평가 용도를 표시한다.

## 결과

로컬 벤치마크 프로젝트 3에 모든 시험과 이전 파일을 보존한다.
파형 및 Whisper Base 검사 세부 결과는 `.runtime/benchmarks/four-model-quality.json`에 있다.
시험 실패도 작업 이력에 남긴다. 청취 완료 전 주관적 품질 개선을 확정하지 않는다.

Fish의 최초 실행(job 12)과 메모리 개선 실행(job 18)은 WAV SHA256이 동일했다.
GPU 최대 할당 15894.6→9421.7MiB, 합성 103.97→70.61초,
모델 로딩 110.46→10.49초였다. 단일 실행 비교로, 다른 대본/부하에서 동일한
비율의 개선을 보장하지 않는다. 20.619초 출력의 Whisper CER는 둘 다 4.67%다.

Vulkan 초기 시험(job 19)은 37.88초, CER 185.05%, 반복/누락으로 실패했다.
T0.9/P0.95/minP0.05 시험(job 20)도 CER 91.59%로 실패했다. 가중치 SHA256은
공식 배포값과 일치했다. 유사한 [Vulkan 대본 이탈 보고](https://github.com/Zyphra/zonos2.cpp/issues/10)가
있어 CUDA 빌드로 전환했다. 이 실패를 ZONOS2 모델 자체의 확정적인 한국어 품질로 일반화하지 않는다.

CUDA에서도 공식 샘플링 기본값(job 21)은 9.49초에서 조기 종료(CER 57.94%)했다.
T0.9/P0.95/minP0.05로 조정한 job 22 및 등록 프리셋 재검증 job 23은 모두
18.680초, CER 4.67%, 마지막 문장 일치로 통과했다. 두 WAV의 SHA256은 동일하다.
조정값을 기본 비교 프리셋에 저장했다. 이 한 대본에 맞춘 결과이므로 다른 대본에도
안정적이라고 단정하지 않으며, 실패 이력도 숨기지 않는다.

| 최종 비교 파일(job) | 음성 길이 | Whisper Base CER | 합성 시간(로드 제외) |
|---|---:|---:|---:|
| VoxCPM2 HQ20 (13) | 19.68초 | 1.87% | 66.30초 |
| Qwen3 FP16/SDPA (14) | 19.20초 | 6.54% | 해당 실행에서 별도 기록 없음 |
| Fish S2-Pro (18) | 20.62초 | 4.67% | 70.61초 |
| ZONOS2 CUDA/Q8 (23) | 18.68초 | 4.67% | 11.68초 |

네 파일 모두 파형 클리핑 없음, 자동 전사 끝 문장 일치, 반복·누락 경고 없음.
CER는 Whisper 오인식과 원문의 비표준 표기 영향을 받으며 발음 점수나 청감 순위가 아니다.
이 시험에는 사람의 청취 평가와 독립적인 화자 유사도 측정이 포함되지 않았다.
같은 대본에서 설정을 선택했으므로 별도 검증 대본에 대한 일반화 성능은 미검증이다.
모델별 실행 정밀도·구조·코덱·로드 상태가 달라 속도를 순수한 모델 우열로 해석하지 않는다.

실제 Studio API에서 세 신규 프리셋 선택 가능 및 Qwen 운영 기본값 유지를 확인했다.
전체 회귀 테스트 29/29 통과. 최종 파일은 `data/artifacts/outputs/project-3/prompt-5/`에,
실패 시험을 포함한 메타데이터는 프로젝트 3과 private quality JSON에 보관한다.
